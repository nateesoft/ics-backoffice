หน้าจะสามารถทำ CRUD ได้ทั้งหมดเลย ตัวอย่างเช่น

Step (Filter):
1. verify data to filter
2. response json with success or error message

Step (Validate):
1. verify login vaidate credentials (username and password)
2. response json with success or error message

Step (Create):
1. verify payload
2. execute insert to database
3. response json with success or error message

Step (Update):
1. verify key and payload
2. execute update to database
3. response json with success or error message

Step (Delete):
1. verify key to delete
2. execute delete from database
3. response json with success or error message
